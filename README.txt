ПРОЯ PWA — публикация на GitHub Pages

Загрузите содержимое этой папки в корень репозитория bkd04/proya, заменив существующие файлы при запросе.
Обязательные файлы:
- index.html
- style.css
- script.js
- manifest.json
- sw.js
- папка icons/ со всеми PNG

После Commit changes дождитесь успешного GitHub Pages deployment.
На iPhone откройте сайт в Safari, дождитесь полной загрузки и выберите Поделиться -> На экран Домой.
Первый запуск должен быть онлайн: тогда service worker сможет сохранить файлы для работы офлайн.

Планы приложения хранятся в localStorage браузера на этом устройстве. Очистка данных сайта может их удалить; они не синхронизируются автоматически между устройствами.
