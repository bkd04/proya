ПРОЯ — календарний прототип

Це тестовий вебзастосунок для Windows, який можна відкрити у Chrome або Edge.

Як запустити:
1. Розпакуйте ZIP-архів у папку.
2. Відкрийте index.html у Chrome або Edge.
3. Натисніть «Новий план», введіть назву, дату й час та збережіть.
4. План з'явиться в календарі на вибраній даті. Натисніть дату, щоб переглянути плани.

Що є в прототипі:
- місячний календар із кольоровими позначками планів;
- створення плану з датою, часом і категорією;
- відмітка виконання та видалення;
- фокус дня;
- проста статистика виконаних планів;
- локальне збереження в браузері.

Важливо: дані зберігаються лише в цьому браузері на цьому пристрої. Синхронізації між комп'ютером та iPhone поки немає. Для встановлення на iPhone потрібно розмістити сайт на HTTPS-хостингу.
